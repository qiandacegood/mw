# 状态矩阵

日期：2026年10月8日  
角色与页面状态交叉。空单元格表示该页对该角色保持默认可浏览，无额外阻断。

图例：可操作 / 只读 / 阻断并给下一步 / 不适用。

## 1 角色 × 核心页面

| 页面 | 游客 | 免费会员 | 有效 VIP | 过期 VIP |
| --- | --- | --- | --- | --- |
| 首页 | 浏览；无继续练习；CTA=注册 | 继续练习、总分等级 | 同免费 + VIP 推荐卷可进 | 同免费；VIP 卷入口提示续期 |
| 分类 / 列表 / 详情 | 可浏览，详情无答案；开始=注册墙 | 免费卷详情可开始；VIP 卷详情=VIP_REQUIRED，不能开始 | 两类卷详情均可开始 | 免费卷同免费会员；VIP 卷详情进入已有草稿，不删已答 |
| 答题 / 答题卡 | 不适用 | 仅免费卷可走完答题卡与交卷；VIP 卷不可进入 | 可 | VIP 草稿可查看已保存答案；恢复或交卷提示续期，草稿保留 |
| 结果 / 解析 | 不适用 | 本人已交卷可看，含曾做 VIP 卷 | 可 | 历史解析可看；未做的 VIP 卷不可借历史偷看 |
| 排行榜 | 前百只读，无本人 | 本人条视参与开关 | 同免费；计分含 VIP 卷 | 同免费 |
| VIP 中心 | 注册后可买 | 开通 | 续期 | 重新开通 |
| 订单 | 注册后 | 本人订单 | 本人 | 本人 |
| 我的 | 登录/注册墙 | 成长订单入口 | 显示到期时间 | 显示已过期 |

## 2 页面状态 × 场景

| 页面 | 空白 | 加载 | 错误 | 处理中 |
| --- | --- | --- | --- | --- |
| 首页 | 无推荐/无类目：说明运营未发布 | 骨架屏 | 网络失败 + 重试 | 内容维护条：仍可看订单 |
| 分类 | 该类无卷：去其他类或首页 | 树骨架 | `CATEGORY_UNAVAILABLE` | `CONTENT_UPDATING` |
| 列表 | 筛空：清空筛选 | 列表骨架 | 重试 | 维护中不可新开卷 |
| 详情 | 已下架：说明原因 | 详情骨架 | 不存在或无权限 | 撤回中不可开始 |
| 答题 | 无（至少 1 题） | 题块加载；失败可重载图片 | 保存失败、冲突、撤回 | 交卷处理中，禁止再点交卷 |
| 结果 | 无成绩：回首页 | 查询提交状态 | 超时先查原 attempt | 评分处理中 |
| 排行 | 零人上榜 / 分类无分 | 榜骨架 | 刷新失败仍展示上一代+延迟 | 新快照未切换，标更新中 |
| VIP / 订单 | 无订单 | 套餐加载 | 渠道不可用 | 确认中 / 开通中，主按钮=刷新 |
| 后台列表 | 无数据 + 新建 | 表格骨架 | 权限不足或校验失败 | 导入 staging / 迁移 job |

## 3 订单展示组合

| 用户可见 | payState | grantState | 主操作 |
| --- | --- | --- | --- |
| 待支付 | pending | pending | 继续支付 / 关闭前先查单 |
| 确认中 | confirming | pending | 刷新 |
| 已支付 | paid | pending | 刷新，禁止再买 |
| 开通中 | paid | processing | 刷新 |
| 已完成 | paid | granted | 查看权益 |
| 已关闭 | closed | pending | 重新下单（新幂等键） |
| 退款处理中 | paid/closed | * | 查看进度；iOS 看指引 |

## 4 答题保存态

| 状态 | 展示 | 可交卷 |
| --- | --- | --- |
| 保存中 | 黄点 + 保存中 | 可以，交卷带最终答案，不依赖未完成保存 |
| 已保存 | 绿勾 + 时间 | 可以 |
| 保存失败 | 红字 + 重试 | 可以，但需提示可能未同步的题 |
| 版本冲突 | 模态：用服务器 / 用本页 | 先解决 |
| 已提交 | 整页只读 | 否，去结果 |

## 6 整改后必须可点路径

| 路径 | 角色 | 期望 |
| --- | --- | --- |
| 免费卷详情 → 开始 → 答题卡 → 交卷 → 结果 → 解析 | 免费会员 | 全程可点，不经过 VIP 墙 |
| VIP 卷详情 | 免费会员 | 服务端语义 VIP_REQUIRED，无开始 |
| 一级 → 二级 → 三级，面包屑返回 | 任意可浏览 | 最多三级，可逐级点 |
| 首页草稿 → 查看已保存答案 → 续期后交卷 | 过期 VIP + VIP 卷 | 草稿不删，交卷被拒并提示续期 |
| 题图 / 解析图 | 答题或解析页 | 点开放大层，点关闭收起 |

走查时用原型顶栏切换角色与页面状态，核对本表而不是另造状态。
