## 2 布局

### 小程序

- 设计宽 375，内容左右 16。
- 底部 Tab 四项等高，图标 + 文字；答题栈页面隐藏 Tab。
- 题干区可滚动，底部固定「上一题 / 下一题 / 交卷」。
- 图片默认最大宽 100%，点击进入放大层；加载失败显示重载，不把缺图当完整题。
- 多选题标签固定文案「多选题」，不显示正确项数量。

### 后台

- 最小可用宽 1200；左侧 220 导航，右侧内容。
- 危险操作使用独立确认条：影响数量 + 原因 + `confirmed`。
- 题库管理员侧栏不出现「订单明细」入口。

## 3 组件

| 组件 | 规则 |
| --- | --- |
| 主按钮 | 主色实心，高度 44，禁用时不降低对比到无法辨认 |
| 次按钮 | 描边 |
| 权限标签 | 免费：灰底；VIP：强调色 |
| 难度 | 入门 / 进阶 / 挑战 三个中文标签 |
| 保存状态 | 保存中（旋转）/ 已保存（绿）/ 保存失败（红，可点重试） |
| 空状态 | 插画占位 + 一句原因 + 一个下一步 |
| 错误 | 原因 + `requestId`（开发态可见）+ 重试 |
| 处理中 | 不诱导重复购买或重复交卷 |

## 4 无障碍与适配

- 可点击区域不小于 44×44。
- 支持系统大字号；长题干换行，不缩小到不可读。
- 色块不作为唯一信息：VIP、错误、已答另有文字。
- 窄屏（320）仍能看到交卷按钮。
