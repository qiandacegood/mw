# 走查清单

在浏览器打开 `prototypes/index.html`（或仓库根静态服务下的 `docs/design/prototypes/index.html`）。必须实际点击，不能只读文案。

## 小程序

1. 角色=游客：首页 → 免费卷详情 → 注册（协议未预勾选）→ 先浏览。
2. 角色=免费会员，免费卷：详情（标签「免费」）→ 开始练习 → 答题 → 答题卡 → 确认交卷 → 结果 → 解析。
3. 角色=免费会员，VIP 卷：详情出现 VIP_REQUIRED，没有「开始练习」。
4. 分类：逻辑思维 → 演绎推理 → 条件判断；面包屑回到上一级。
5. 角色=过期 VIP：首页「继续草稿」→ 查看已保存答案 → 答题卡可见已答 → 交卷进入续期，返回草稿仍在。
6. 答题或解析页：点击占位图出现放大层，再点「关闭」消失。
7. 角色=有效 VIP：VIP 详情可开始。
8. 页面状态=空白 / 加载 / 错误 / 处理中：首页、列表、排行、订单各看一次。
9. 勾选大字号：题干与按钮仍可见。
10. VIP 购买：占位价 → 确认支付结果「开通中」→ 刷新，无「再买一次」主按钮。

## 后台

1. 题库管理员：侧栏无订单金额；会员页提示不能看订单明细。
2. 运营管理员：订单可见；执行退款按钮禁用。
3. 超级管理员：执行退款、成长、榜单、管理员可见。
4. 类目页第四级预览拒绝。
5. 导入页强调半批不可见。
6. 页面状态=处理中：维护任务不能跳过校验。
