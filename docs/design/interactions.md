# 关键交互

日期：2026年10月8日  
可在 [小程序原型](prototypes/miniprogram.html) 与 [后台原型](prototypes/admin.html) 逐步点选。

## 1 游客浏览到注册

1. 游客可看首页、分类、试卷介绍、公开榜。
2. 点「开始练习」出现注册墙：协议与隐私未预勾选。
3. 拒绝：留在公开页，答题入口仍提示注册。
4. 同意并注册：建立 `memberId`，默认昵称头像，`rankingOptIn=false`。
5. 回到原目标试卷详情。

## 2 选卷与权限

1. 分类最多三级，面包屑可回退；父级列表含后代卷，按 `paperId` 去重。
2. 列表可筛难度、免费/VIP、未做/已做；不可把该筛选带到排行榜。
3. 详情不展示答案。免费会员点 VIP 卷：服务端 `VIP_REQUIRED`，保留「去开通」而不是开始。
4. 过期 VIP 与免费会员相同判权；已提交的历史解析仍可打开。
5. 已有进行中草稿时开始另一卷：必须明确继续或放弃，不自动丢弃。

## 3 答题、保存、交卷

1. 选择即请求保存；按钮区显示保存中 / 已保存 / 保存失败。
2. 仅服务端确认后才显示已保存。断网提示「当前选择尚未同步」。
3. 跨设备 `DRAFT_CONFLICT`：用户选择保留服务器或重发本页，禁止静默覆盖。
4. 答题卡可跳转任意题；交卷前可改。
5. 存在未答题：二次确认「未答计 0 分」。
6. 交卷超时：按原 `attemptId` 查状态，不新建一轮。
7. 重复提交同一记录返回同一结果。

## 4 结果与解析

1. 结果立即显示本次分、满分、正确题数、历史最高、本次新增、等级变化。
2. 解析仅已提交本人可见：我的选择、正确答案、得分、解析。
3. 「只看错题及未答」为筛选，不是独立错题本。
4. 再次练习创建新记录，绑定当前发布版本。

## 5 排行榜

1. 四个 Tab：总分、分类、本周、本月。分类必须选有效类目。
2. 显示更新时间与 `generation`；滞后时文案为「更新延迟」，不伪造时间。
3. 游客无本人条。未参与会员见「未参与公开排行」+ 开启开关。
4. 并列展示 1 / 1 / 3；零分不上榜。
5. 无 `免费卷榜` 筛选项。

## 6 VIP 购买

1. VIP 中心展示权益、到期、占位套餐天数与占位价。
2. 确认套餐后创建订单（冻结价格与天数），再拉起收银台。
3. 返回后固定进入「确认支付结果」，客户端 success 不开通。
4. 待支付 / 确认中 / 已支付 / 开通中 / 已完成 / 已关闭按三维状态组合显示。
5. 已支付未开通：主按钮是「刷新状态」，禁止「再买一次」主路径。
6. 取消收银台 ≠ 已关闭；先查单。
7. iOS 订单售后只给 App Store 指引，无「商户退款」按钮。

## 7 后台危险操作

1. 改父级、删除引用、纠错、退款执行、成长门槛发布均先预览。
2. 预览绑定 `previewId` + `planHash`，10 分钟或对象版本变化后失效。
3. 题库角色看不到订单金额明细。运营不能点「执行退款」或「改分」。
4. 导入：先校验预览，阻断错误整批拒绝；提交后显示批次状态，半批按 ID 也不可见。
