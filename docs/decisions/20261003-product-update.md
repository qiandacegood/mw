# 思维工坊需求更新记录

日期：2026年10月3日  
现行产品版本：[V1.1](../product/product-spec-v1.1.md)  
历史版本：[V1.0](../product/product-spec-v1.0.md)

## 用户明确决定

1. 类目支持增减删除，最多三级；原十类作为初始配置。
2. 移除排行榜免费试卷筛选，免费与收费试卷统一计入榜单。
3. 小程序采用腾讯云 CloudBase。
4. 无需进一步裁决即可推进的事项，直接编制相关技术文档。

## 本次补充设计

类目允许一至三级节点直接挂卷，父节点汇总本节点和全部后代，按试卷去重。引用中的类目删除先迁移当前题目与试卷，历史快照及成绩保留，使用逻辑删除。调整父级和迁卷只改变分类归属，不改变总分与周月新增分。这些是为落实三级类目而制定的设计细节，不记为用户逐项口述决定。

分类迁移和成绩纠错使用短时内容维护任务，保留草稿与支付处理能力，避免半套分类口径。后台显示预览与影响后确认，属于产品运行中的操作流程，不是本轮要求用户重复授权编写文档。

技术方案采用原生小程序、Vue 3 后台、TypeScript 服务端、CloudBase 文档数据库、云函数、云存储及静态托管。Node 运行时在 CloudBase 支持范围内完成验证后冻结，没有锁定部署资源或发生费用。

## 影响范围

更新产品说明、目录说明与项目入口；新增技术架构、数据与索引、接口契约、一致性处理、支付、部署运维、验收计划及技术阅读入口。

V1.0 原文件保持不变，保留当时免费筛选和固定一级分类等历史设计；后续工作只以 V1.1 为现行入口，不从历史版本继承冲突规则。

## 尚待真实配置

实际 CloudBase 环境及地域、运营主体与 AppID、支付资格、预算、首位后台管理员、VIP 价格、客服与正式协议，按部署及售卖阶段确认。本轮没有必须先裁决才能完成技术文档的问题，也没有创建、购买或部署云资源。
