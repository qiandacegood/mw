## 编号与记录位置

MW01—MW30 是开发任务；A01—A31 是产品验收项；T01—T30 是技术测试场景，三者不可混淆。

first-batch 保存临近启动任务的执行说明；first-batch/results 保存真实执行和验收结果。此命名只是沿用熟悉的目录风格，目录命名本身不代表状态，实际状态见 [07-progress.md](07-progress.md)。也不要求立即为所有任务建立文件。

更新设计规则时同步对应产品或技术资料；更新完成状态时只改实际进度并链接结果。涉及范围、预算或正式发布的改变由负责人决定，普通已安排范围内的实现按任务继续，不反复申请相同权限。

## 后续使用方式

每次开始一项，先读实际进度，再读任务总览相应行和必要设计资料，确认已有依赖产物；执行后交付可见结果、有限检查和限制，再回写进度。MW01—MW03 已完成，MW04 部分完成，下一项为 **MW05 可有限启动**。

此处不预定工期、不新建任务数据库、不安装自动化，也不以“可独立推进”自动安排多个执行者。具体开发执行遵循后续任务安排，本轮工作限于规划和规则文档。
