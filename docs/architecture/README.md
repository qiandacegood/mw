## 开发前的有限技术验证

以下由开发阶段完成，未通过时修正文档后再实现依赖功能，不能用设计文字替代验证：

- 目标 CloudBase 传统文档模式、运行时可用性及生产支持状态；Node SDK 事务、身份上下文和 Web 管理员登录的版本组合。
- 六种入口的真实权限边界，原生小程序云身份不自动等同已注册会员。
- 索引、私有图片短期读取、5 MB 导入上传是否在目标网关限制内。
- 虚拟支付主体和双端商品能力，回调协议、发货确认及 Apple 退款处理。
- 事务最大操作数、冲突重试、结构维护排空及榜单刷新开销。

验证对象均有界，不先建设通用平台。应用开发先完成结构与答题闭环，同时尽早验证支付资格，最终交付必须包含在线支付与四维排行榜。
