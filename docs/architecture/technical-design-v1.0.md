# 思维工坊技术架构 V1.0

日期：2026年10月3日  
依据：[产品说明书 V1.1](../product/product-spec-v1.1.md)  
状态：可用于开发拆分的设计基线；没有部署、付费开通或运行验证。

## 1 技术选型

| 层次 | 首版选择 | 说明 |
| --- | --- | --- |
| 小程序 | 微信原生小程序、TypeScript、WXML、WXSS | 原生云调用和虚拟支付；不增加跨端框架 |
| 管理后台 | Vue 3、TypeScript、Vite | 单页应用，部署于 CloudBase 静态托管 |
| 服务端 | TypeScript 编译为 JavaScript，CloudBase 云函数 | 采用模块化业务代码，不拆微服务 |
| 数据库 | CloudBase 文档型数据库 | 不另建 PostgreSQL、MySQL 或 Redis |
| 文件 | CloudBase 云存储 | 私有题目及解析图片、导入文件；公开品牌资源随前端发布 |
| 小程序身份 | 云调用提供的可信微信身份 | 业务注册仍需确认协议 |
| 后台身份 | CloudBase 身份认证账号密码登录 | 账号预建，角色保存在服务端白名单，关闭自行获得后台权限 |
| 服务端 SDK | @cloudbase/node-sdk | 数据访问、事务和可信云调用上下文，集中封装 |
| Web SDK | @cloudbase/js-sdk | 认证及调用后台函数，不直连业务集合 |
| 支付 | 微信小程序虚拟支付，道具直购 | CloudBase 承载业务后端，不替代微信支付资格 |

CloudBase 提供上述数据库、存储、认证、云函数与静态托管能力。[CloudBase 文档中心](https://docs.cloudbase.net/)

版本策略：应用依赖在初始化时锁定明确版本和 lockfile，不在部署时自动追随 latest。运行时以 Nodejs22.21 为初始候选；2026年10月3日官方配置页列为支持但仍标注公测，必须先核实目标环境可用性、SDK 兼容性与生产支持政策，再在部署清单冻结最终版本，不静默降级。当前文档不代表已选定可部署环境。[云函数配置](https://docs.cloudbase.net/cli-v1/functions/configs)

## 2 部署单元与职责

| 函数 | 入口 | 职责 |
| --- | --- | --- |
| mw-public | 小程序云调用 | 类目树、已发布卷介绍、榜单等公开只读数据 |
| mw-member | 小程序云调用 | 注册、本人资料、答题、成绩、VIP、订单与支付准备 |
| mw-admin | Web SDK 云调用 | 后台角色校验、内容、配置、会员及订单操作 |
| mw-upload | HTTPS | 经一次性上传票据验证的后台文件上传 |
| mw-pay-hook | HTTPS | 平台验证、支付发货通知、退款及问询；独立协议响应 |
| mw-jobs | 定时触发及可信服务端调用 | 补偿、导入、排行快照、纠错、分类迁移和对账 |

这些是函数部署边界，业务实现共享 services/api 下的领域模块。公开函数不能依据客户端 action 转发到后台或支付写逻辑。

普通业务不开放无鉴权 HTTP 副本。mw-pay-hook 必须允许支付平台到达，不能套用要求会员登录的网关；其安全性来自官方签名校验和订单核验。mw-upload 的票据由已授权管理员经 mw-admin 获取，只允许指定用途、大小、类型与对象位置，不能以“链接复杂”代替鉴权。

## 3 身份与信任边界

小程序请求中不接受 userId、openid、role、score、vipExpiresAt 作为可信身份或结果。服务端 SDK 从云运行上下文读取 appId、openId 等，校验 AppID 和当前环境，映射内部会员标识。正式会员记录仅由 member.register 在确认有效协议版本后建立，云平台自动识别微信用户不等于业务已注册。

后台由 CloudBase 身份认证管理密码；函数从可信上下文取 uid，再读取 admin_users 判断启用状态和角色。普通 CloudBase 登录用户没有后台权限。超级管理员首次引导通过受控离线管理操作建立，不设公开“注册为管理员”接口。

官方 Node SDK 的 getUserInfo 从运行上下文取值；客户端传入同名字段不能替代它。[腾讯 CloudBase Node SDK 身份实现](https://github.com/TencentCloudBase/node-sdk/blob/master/src/auth/index.ts) 后台登录能力参考[CloudBase 身份认证](https://docs.cloudbase.net/authentication-v2/auth/introduce)。

所有业务集合默认禁止客户端直接读写，服务端通过明确的响应白名单返回数据。云函数安全规则只能作为第一层入口限制，仍须在函数内逐 action 校验角色与资源归属。[函数安全规则](https://docs.cloudbase.net/cloud-function/security-rules)

## 4 数据与响应分层

题目公开作答内容和正确答案、解析分别保存。试卷版本的公开内容只在权限通过后返回；服务端评分读取私有答案块。结果解析只对已交卷记录的本人或内容管理角色开放。图片也按用途分开，不能把解析图片 URL 提前随题目返回。

CloudBase 云存储设为客户端默认不可读写，服务端校验后签发短期读取链接；公开品牌图片进入前端静态资源。后台上传先进入隔离路径，校验真实图片格式、大小和摘要后才能成为可引用素材。[云存储安全规则](https://docs.cloudbase.net/storage/security-rules)

临时链接有失效时间，但已经下载的内容无法收回；禁止宣称可以防止用户截图或转发已授权看到的题目。

## 5 同步与异步边界

必须同步原子完成：交卷结果与该卷最高分、总分及分数事件；付款确认与唯一发放任务；VIP 发放与订单发放标识；退款结果与后续撤销任务。外部支付调用不得放进数据库事务。

可以异步：勋章授予、公开排行快照、分类重建、大批导入、纠错及对账。事务内同时落持久任务记录，成功响应后不能只依赖函数内存中的 Promise 或后台定时器继续工作。

CloudBase 文档数据库事务目前仅服务端支持，官方列出的限制包括最多 100 次操作、30 秒及事务内按 doc 标识访问。设计按每次事务不超过 60 次操作、单次目标低于 3 秒控制，留出余量；1000 行导入不能塞入一个事务。[数据库事务](https://docs.cloudbase.net/database/transaction)

事务自动重试只运行数据库内的幂等逻辑；发支付请求、发退款请求、上传文件等外部动作必须在事务之外有独立业务编号与结果查询。

## 6 类目与成绩一致性

类目树使用稳定节点标识、父标识和祖先路径，深度最多三。每卷直接挂一个节点，父级分包含其后代试卷，不能把父级和子级分叠加为总分。

改名和排序可快速发布；改变父级、批量迁卷、删除带引用类目需要预览。首版采用受控的短时内容维护任务，暂停相关结构写入、开始答题及交卷，允许保存草稿和支付，等待在途事务结束后迁移并重建分类投影。失败时保持维护状态和可恢复检查点，不开放混合口径。

总分、周月分差只依赖稳定试卷与交卷事件，结构迁移不得增减这些分值。原答题快照保存旧路径，当前分类视图使用新路径。[一致性流程](consistency-v1.0.md)规定发布、排空和恢复顺序。

## 7 时间与规模约定

内部时间统一 UTC 毫秒或数据库 Date；API 返回带 Z 的 ISO 8601。界面与周期边界使用 Asia/Shanghai。VIP 天数按 24 小时，金额按整数人民币分，业务分按整数。

数据库内部随机实体 ID 使用服务端生成的标识；幂等组合键使用完整 SHA-256 编码，不拼接不受限输入。对外不泄露微信身份或平台密钥。

初始性能验证使用 1 万会员、1000 张卷、10 万答题记录，不承诺超过此规模仍无需优化。榜单按快照展示名次；每次请求不全表扫描和排序。正文及选项不超过应用定义的字段长度，单个快照块限制 256 KiB，题目过长时发布失败并明确指出原因。

## 8 源码规划

沿用已有空目录，不另建第二份后端：

- apps/miniprogram：页面、组件、接口适配器和微信支付封装。
- apps/admin：管理页、登录、角色路由与表单；路由权限仅改善体验。
- services/api/src/entrypoints：上述六个函数入口。
- services/api/src/modules：identity、catalog、quiz、scoring、growth、ranking、billing、imports、audit。
- services/api/src/adapters：cloudbase、wechat-virtual-pay、storage、clock。
- packages/shared：纯类型、参数校验定义、错误码；不包含答案与密钥。
- infra/cloudbase：部署描述、集合与索引清单、安全规则模板。
- scripts：构建、迁移与有限初始化；禁止自动创建付费环境。
- tests：集成、并发、越权、回调重放与端到端检查。

本轮只编写文档及目录说明，以上源码文件与部署配置将在开发阶段创建。
